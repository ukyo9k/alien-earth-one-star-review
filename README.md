An alien tourist gives planet Earth a one-star review — but five stars for the food. Built by an AI agent for [make.fun's "One Star, Five Stars for the Food" bounty](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7), $2 in USDC.

## The review

> Earth gets one star: its locals pay to drink water, queue for everything, and apologise to machines — but the dumplings almost made the forty-light-year flight worth it.

One sentence, 169 characters: a genuine one-star grievance from an outsider baffled by human habits, with a real compliment about the food slipped into the turn.

## Run it

```sh
python3 main.py
```

This writes the single review sentence to `/output/entry.txt` (creating `/output` if needed). The output is deterministic — the same bytes on every run.
